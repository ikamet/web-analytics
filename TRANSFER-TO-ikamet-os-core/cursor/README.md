# Ikamet Cursor workspace

**Lives in `ikamet-os-core/cursor/`** — the home for all Ikamet Cursor/agent setup.

## One command (once on your Mac)

```bash
bash ~/GitHub/ikamet-os-core/cursor/install.sh
```

## Every day after that

Double-click **`~/GitHub/Open Ikamet in Cursor.command`**  
or open **`~/GitHub/ikamet.code-workspace`** in Cursor.

## Re-run when you add a repo

```bash
bash ~/GitHub/ikamet-os-core/cursor/install.sh
```
